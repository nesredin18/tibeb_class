EthioVerify Verify Tester

Local browser-only tester for direct-verify and webhook verify. It sends multipart/form-data directly from this page to the verifier API. If the browser shows CORS or network failure here, the issue is outside your Django backend.

This page uses the request header X-EthioVerify-Key. Direct verify waits for verification output. Webhook verify should return quickly with a pending/request ID, then EthioVerify later calls your configured webhook.
